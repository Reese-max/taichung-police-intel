# GovIntel 第一批資料範圍與 AI 預審紀錄草案

**狀態：** DRAFT_FOR_CONFIRMATION。本文是範圍建議與狀態整理，不變更來源權利決定、正式准入、模型傳輸設定或 production 啟用狀態。

## 1. 試辦目的與範圍

建議第一批先完成 M1「議會監督與備詢」文字資料閉環，供警政機關內部議會備詢、議題整理與裁示後續追蹤使用。正式營運單位、適用人員與核准用途仍待機關確認。對外公開、個人風險評等、個案偵查或勤務決策用途不在本試辦範圍。

| 欄位 | 草案值 |
| --- | --- |
| 範圍 ID | `M1-TEXT-PILOT-2026-09-01--2026-10-07` |
| 日期窗口 | 2026-09-01 至 2026-10-07，含起訖日；日期以 `Asia/Taipei` 解讀 |
| 納入依據 | 官方證據所載的實際會議日期；以官方會期／會議關聯作交叉核對 |
| 資料來源 | S-004、S-006、S-007、S-009、S-029 |
| 擷取截止 | 執行時記錄精確時間與時區；本草案不預填尚未發生的擷取時間 |
| 後續批次 | S-010、S-011 影音、音軌、字幕與 ASR |

這個窗口沿用既有 pilot 的日期界線，方便重現既有歷史觀測。它是有界的歷史試辦，不代表即時資料完整或目前狀態。

## 2. 納入、日期與版本規則

1. 清點窗口內實際開會日的全部官方會議項目；以官方索引的完整分母為準。每一項需有原件或明確缺件原因。
2. S-007 以窗口內的完整會議紀錄作為清點單位。「警察局」關鍵字結果可作警政主題標籤，不能單獨代表完整議事錄範圍。
3. S-009 提案及 S-029 專案報告依官方會期、會議或議案關聯納入。無法驗證關聯者列為待釐清，不併入已驗收分母。
4. 會期、實際會議日期、列表日期、文件發布日期、附件修訂日期、決議／辦理日期與擷取時間分欄記錄。主日期缺失時標記 `UNKNOWN`，不以列表或擷取日期代填。
5. 窗口內會議所屬文件即使在窗口外發布或修訂，也可列入其關聯文件；發布／修訂時間仍按原值記錄，不改寫成會議日期。
6. 附件範圍包含官方列表或詳頁直接連結、且可確認隸屬於範圍內項目的附件。保存 URL、格式、位元組數、SHA-256、版本線索、頁數及解析結果。取不到者記錄缺件原因。
7. 歷史版本收錄官方明確提供、且能關聯至範圍內項目的版本。來源未提供歷史版本索引時，標記 `HISTORY_NOT_VERIFIABLE`；不可把首次觀測版本稱為完整修訂史。
8. 附件中的第三方素材、個人資料或特殊權利標示須獨立標記；其權利與必要性未完成真人審查前，不納入可展示、可摘要或可傳輸內容。
9. 正文也要檢查個資、案件細節、未成年人或其他敏感內容，依任務必要性做欄位／段落最小化與遮蔽；審查及遮蔽規則未定前，不把相關內容送進模型或公開輸出。

## 3. 完成條件

- 範圍內官方索引項目都有原件或逐筆缺件理由，並保留官方清冊分母。
- 附件 manifest 可由會議／議案回查至原始連結、版本、雜湊與頁碼；無法解析或取得的附件仍列入清冊。
- 日期欄位彼此分離，未知值不推測補齊。
- 至少一條「議程／提案 → 議事錄 → 正式報告或答覆 → 有定位引用的摘要」能回查至精確文件版本與頁碼。
- 影音資料不混入本批文字驗收；「會議中提及」不推論為「已辦理完成」，除非有後續正式證據。

## 4. 20 筆來源的 AI 預審狀態

使用者於 2026-10-12 表示：20 筆來源都由 AI agent 審查，目前沒有真人審查者，也沒有正式決定。此說明已另存於 [`source-reviews/2026-10-12/ai-pre-review-status.json`](source-reviews/2026-10-12/ai-pre-review-status.json)。由於未提供各 agent／模型識別、審查輸入雜湊及逐筆輸出文件，這些細節維持未知，不能宣稱已獨立核驗 AI 審查產物。

清冊應將 AI 工作記為「AI 初步審查」，並與正式真人審查欄位分開。真人 reviewer、職權、日期與決定仍待具權責人員填寫。20 筆來源的權利狀態維持 `UNKNOWN`，目前沒有模型傳輸授權，正式准入與 promotion 不變更。此前 AI 預審是否把來源原文或附件送至外部模型服務尚未核實，須補查服務、輸入內容、處理地區與留存情形。

AI 預審產物至少應保存 agent／模型版本、prompt 或檢核表版本、執行時間、輸入文件雜湊、逐項引據、未知事項及建議。AI 建議不得自動改寫真人 reviewer、正式決定或權利狀態。

## 5. 待機關確認欄位

- 是否採用上述日期窗口與 M1 文字來源清單。
- 實際營運單位、內部受眾及核准業務目的。
- 負責正式來源／用途審查的真人角色與其授權範圍。
- 原文、附件、摘錄、摘要、索引／向量與模型傳輸各自的決定。
- 若允許模型處理：服務商、模型、處理地區、輸入欄位、推論／嵌入／訓練用途、留存、刪除與次處理者。
- 原件、全文索引、摘要、快取與備份的保存期限，以及更正、撤回與刪除流程。
