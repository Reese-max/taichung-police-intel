# GovIntel AI－v6 四分鐘展示與備援

提案：**GovIntel AI－公共資訊查詢與個人化追蹤平台**。以下時限是內部演練安排，不是主辦官方簡報規定。主要流程對應 v6 p2–4 的民眾道路查詢與站內追蹤；交班與議會影音留作既有基礎補充。

## 計時前固定展示範圍

先依 [JUDGE_PATH](JUDGE_PATH.md)準備既有依賴，再於 repo 根目錄執行下列命令；準備時間不計入四分鐘。公開受限流程的固定基準見 [10/7 驗收包](closure-20261007-pr177/README.md)，本機重播保留自己的 checkout SHA／lockfile 與 receipt，不沿用正式站版本。

```bash
git rev-parse HEAD
python3 -X utf8 scripts/replay-commute-reopen.py --self-check
npm --prefix apps/web run build
python3 -m http.server 8000 --bind 127.0.0.1 --directory apps/web/out
```

開啟 `http://127.0.0.1:8000/public-query/`。資料使用經 bundle SHA-256 核對的 [public-query-replay.json](../../../apps/web/public/data/public-query-replay.json)，情境截止 `2026-10-10T09:00:00+08:00`；不是今天的公告，也不是來源身分的數位簽章。用專用瀏覽器 profile 演練，保留原本瀏覽器的條件。這是保存快照的合成重播；啟動靜態伺服器不代表已封鎖瀏覽器對外連線，官方原文／影音仍可能需要網路。合成 locator 在頁面內檢視，不把 `synthetic.invalid` 當成可開啟的官方來源。

不呼叫 collector、模型或付費服務；資料、模型、真人與 deployment 各有驗收範圍。準備與測試依賴需先安裝，靜態產物建立後才可斷網重播本流程。

## 0:00–0:35 任務與現況

說明使用者想知道「測試路 A 到 B 路口的工程何時結束」，並希望下次開站看見工期是否延長。這是合成道路及公告，不代表真實道路安全或已取得的正式四類來源。

讀[CURRENT_STATUS](CURRENT_STATUS.md)：核准 baseline 為五來源；v6 query／tracking／eval PR 已合併到 main，受限正式部署已驗，正式權利准入與真人成效仍待驗收。新功能演示若來自本地，螢幕先標版本與`SYNTHETIC`／`OFFLINE_REPLAY`。

## 0:35–1:25 查詢與保存條件

在本機 `/public-query/` 的「資料模式」選 **合成通勤示例 · 保存快照重播**，再選「重播節點」**R1**（不可沿用預設 R3）。展開 **合成示例篩選條件（僅在示例中可用）**，路段填 `測試路 A 至 B`，期間填 `2026-10-05T09:00` 到 `2026-10-07T17:00`，每日起訖填 `09:00`／`17:00`；其餘條件留空後按「查詢」。v1 應只顯示這次工程，檢查套用條件、原始合成 payload／locator 與時間，不把正式模式尚未提供的路段篩選說成已上線。

按 **將這組實際套用條件加入追蹤**，看到保存成功後開「我的追蹤」`/tracking/`。「資料範圍」選 **合成通勤重播（與真實清單隔離）**，「重播資料截止」選 R1。條件與已讀版本存同一瀏覽器，不要求住址、登入或敏感身分。首次資料列為初始清單，不叫「今日新增」；「公開發布快照」是另一份清單。

## 1:25–2:30 重開站看延長與去重

在追蹤頁依下表切換「重播資料截止」R2 → R3。v2 把結束日 10 月 7 日延到 9 日；每日時段與 A–B 範圍不變。展開 v1／v2 合成原文與差異，再按 **標記這次更新已讀**。重新整理後須再次選合成資料範圍與 R3，核對已讀不重複；快照選項本身不是持久化的使用者條件。

重播同源轉載與純排版版本，應保留來源／版本但不新增重要提示。另一次實質更正仍可列出，不被過度去重吞掉。來源失敗／過期時保留 LKG 與缺口，不推論道路已恢復。

## 2:30–3:15 明文解除與取消

先選 R6，確認過了預定時間仍保留條件；再選 R7，v3 另有 10 月 9 日 17:00 起解除的明文，`UPD-006` 應有一次未讀提示。標已讀後條件仍啟用，不能把某次工程解除當成使用者取消條件。按 **取消追蹤條件** 後選 R9，確認停止該條件站內提示；原合成公告仍可查詢。缺 v3、到期、列表消失或來源失聯均不能標解除。

說明只有開站／刷新才比對；關站不背景推播。本機 storage 被清除可能失去清單，跨裝置及帳號不是首期承諾。

## 既有基礎與故障備援

需要補充時再開議會 evidence drawer、官方影片 timestamp 和來源 health。官方 HLS 失效用原機關入口與明示 fallback；舊 Kiro 影片僅[歷史證據](../historical/README.md)。依 v6 p9，未通過線上來源可交截止時間明確的離線查詢／追蹤驗證包，不宣稱持續最新服務。
