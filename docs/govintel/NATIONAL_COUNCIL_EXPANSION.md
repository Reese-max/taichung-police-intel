## 定位

GovIntel 的用途是**協助警政機關掌握議會與政府對警政業務提出的要求**，以便提早準備答詢、追蹤承諾事項與調度資源。

範圍限制：

- 只整理議會與政府對業務提出的要求、決議與答復。
- 不做個別政治人物、政黨或投票行為的分析、排名或預測。
- 公開輸出以官方原文出處為準；AI 只負責找出與分類，由人工覆核後才採用。

## 盤點方法與限制

- 調查日期：2026-11-15。
- 每個議會只看首頁、議事資訊頁、宣告或著作權頁、robots.txt，以及一兩個樣本頁或 API 回應；未登入、未大量擷取。
- 「查不到」表示在上述範圍內沒找到，不代表確定不存在。「推論」是依網址結構或頁面樣式判斷，未向廠商確認。
- 授權欄只記錄網站上的文字，不是法律判斷。議事內容是否屬著作權法第 9 條不受保護的「公文」，需要法律意見。

## 三、共用平台

現行提案與質詢**沒有跨議會共用的廠商平台**，約需 20 支擷取器，欄位需自行統一。可共用的只有：

| 組別 | 成員 | 可共用程度 |
|---|---|---|
| 國史館臺灣文獻館議事錄系統（`{code}.digital.th.gov.tw`） | 高雄、臺南、桃園、基隆、新竹縣、新竹市、苗栗、南投、雲林、嘉義市、花蓮、連江 | 一支擷取器即可，但只有約 1946–2014 年的歷史議事錄；聲明授權須逕洽各議會 |
| 同一套 CMS（`/tc/*.aspx?mid=`） | 桃園、新竹市 | 版型相同；提案與質詢模組只有新竹市有 |
| 同一套 CMS（`?lang=&program=`） | 新北、新竹縣 | 新北議案系統另用 Blazor，不能共用 |
| YouTube 影音 | 南投、雲林、澎湖、金門、連江、嘉義市、新竹市 | 影音可共用一支擷取器 |

## 四、既有彙整資源

- 文獻館地方議會議事錄總庫：12 個議會的歷史議事錄掃描與詮釋資料，止於約 2014 年；聲明授權須逕洽各議會，下載連結實測無效。
- data.gov.tw：沒有任何地方議會是資料提供機關；僅有市府端的施政或工作報告資料集。
- 民間整理（g0v 議員投票指南、報導者六都議會觀察）：前者停在約 2014 年，後者原始資料未公開。

結論：全國地方議會資料需要從零建置。

## 五、分期計畫（已由全國資料層取代）

2026-11-15 的原計畫是先把臺中市議會全部提案放進既有的靜態 feed（PR #244–#246），再依授權明確程度分四期擴充，到第 2 期才改用資料庫。擁有者 2026-11-17 決定資料層只直連官方系統、另建獨立的全國資料層之後，這份分期不再適用：

- 議會資料存放於 Cloudflare D1（`govintel-national`），由伺服器端搜尋；原計畫「靜態 JSON、列數上限 20,000、搜尋索引下載到瀏覽器」的前提不再適用。
- PR #244、#245 已於 2026-11-25 關閉；#246 只保留「收集器重新建立基準不算官方修訂」這一項修正（#286）。
- 22 個議會全部登記；robots 明文禁止者列為「需議會同意」，不再依原表的四期順序。

工作分期（W0–W8）、各來源的取得方式與回填狀態見 `NATIONAL_DATA_LAYER.md`；最新進度與待辦見 `NEXT_STEPS_2026-11-20.md`。

## 六、主要風險

1. **授權**：22 個地方議會只有新竹市有開放宣告；高雄明文限非商業個人使用，基隆明文禁止未經同意重製，臺中保留所有權利。擴充前須取得各議會書面同意或法律意見。
2. **robots 與技術**：嘉義市、嘉義縣（www）、立法院 ppg 子網站全禁爬蟲，澎湖擋附件目錄；新北需無頭瀏覽器；基隆與嘉義縣的 API 沒有公開文件，可能隨時變動。
3. **欄位統一**：各議會沒有共同格式，屆次、會期、提案類型、委員會名稱都要另建對照。
