# Historical competition / prior prototype evidence

This directory is the boundary for the earlier Kiro competition package and its
prototype receipts. It is preserved for provenance; it is not the current
GovIntel product status and it is not evidence for the 2026 Ministry of the
Interior hackathon.

## Preserved package

- [Historical submission draft](./competition-2026-08/SUBMISSION.md)
- [Historical three-minute demo script](./competition-2026-08/DEMO_SCRIPT.md)
- [Historical submission checklist](./competition-2026-08/SUBMISSION_CHECKLIST.md)
- [Historical Kiro usage evidence](./competition-2026-08/KIRO_USAGE.md)

The package contains the former `Taichung Police Public Intelligence` name,
the 2026-08-23 competition deadline, Kiro-session evidence, the old demo
video, and the original council-evidence path. Those facts remain historical
receipts only. Do not use them to infer current eligibility, current
production freshness, current feature status, or a completed submission.

The archived submission-form link was checked read-only on 2026-10-05:
it redirects to Google's `closedform` page. It is preserved as historical
provenance, not an open form or a route for the current MOI competition.

For the current product and judge path, start at
[GovIntel 2026 competition entry](../competition-2026/README.md).

The root `.kiro/` artifacts remain in place because repository verification
expects them and they document the prior development workflow. Their presence
does not add a Kiro runtime dependency to the current demo.
